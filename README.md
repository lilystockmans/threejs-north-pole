# The North Pole, 90° N

A low-poly Christmas diorama built with Three.js. Santa's workshop, elves, reindeer, snow, and the aurora borealis, all made from code. No models, no textures.

## Features

- Santa, Mrs. Claus, three elves, and reindeer
- Workshop, Christmas trees, campfires, gifts, snowman, and sled
- Falling snow, twinkling stars, and an animated aurora
- Click a tree to light it up. Click the topper star to toggle it.

## Run it

https://north-pole-threejs.vercel.app/

**Controls:** drag to rotate, scroll to zoom, click trees to light them.

## Built with

Three.js 0.170 (loaded from CDN), plain HTML, CSS, and JavaScript.
